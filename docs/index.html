Build iOS 10 XNU from source (arm64) impossible
Public xnu-3789.70.16 ships only config/*_x86_64 — no MASTER.arm64, no arm64 exports. Apple never published ARM64 kernel configs for the iOS 10 era. Clean source build cannot produce an arm64 kernel.
Public arm64 XNU exists from iOS 11+ finding
Only iOS 10 (xnu-3789) is x86_64-only. xnu-4570 (iOS 11), xnu-4903 (iOS 12), xnu-6153 (iOS 13) and xnu-7195 (iOS 14, with MASTER.arm64.iPhoneOS) all ship arm64 kernel configs — so a clean, non-gray source build is possible by targeting iOS 12–14.
Pick the clean target: iOS 12 vs iOS 14 next
iOS 12 (xnu-4903) is 1 GB-RAM class — the best fit for 1.9 GB. iOS 14 (xnu-7195) has the explicit iPhoneOS config — the best build support. Neither needs Apple firmware decryption.

The iOS 10 blocker — and the way around it

iOS 10 arm64 cannot be built from open source — but iOS 11+ can. The public xnu-3789 snapshot is x86_64-only. From xnu-4570 (iOS 11) onward Apple published arm64 configs, and xnu-6153/xnu-7195 even target iPhoneOS. So instead of decrypting firmware, we simply target a slightly newer iOS: iOS 12 fits the RAM and builds clean. 
# oldest public XNU with arm64 kernel configs
$ for t in xnu-3789.70.16 xnu-4570.71.2 xnu-4903.221.2 xnu-6153.141.1 xnu-7195.141.2; do
>   n=$(curl -s .../$t/config | grep -c MASTER.arm64)
>   echo "$t  arm64-configs=$n"
> done
xnu-3789.70.16   arm64-configs=0    <- iOS 10, x86_64 only
xnu-4570.71.2    arm64-configs=2    <- iOS 11
xnu-4903.221.2   arm64-configs=3    <- iOS 12  (1 GB RAM class)
xnu-6153.141.1   arm64-configs=3    <- iOS 13
xnu-7195.141.2   arm64-configs=5    <- iOS 14  (MASTER.arm64.iPhoneOS)
